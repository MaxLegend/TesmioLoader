# tesmioloader — инструкции для пользователя

Пошаговые инструкции простым языком для **игроков**, а не для тех, кто пишет
моды. Если хочется узнать, как загрузчик *устроен внутри* — адреса, хуки,
внутренности движка — это папка `docs/` уровнем выше
([docs/01-architecture.md](../01-architecture.md) и далее). Эта же папка
отвечает только на вопросы «куда нажать», «что написать» и «что должно
произойти».

Начните отсюда:

1. **[00-getting-started](00-getting-started_RU.md)** — установка, запуск,
   включение/выключение плагинов, безопасное изменение настройки, чтение
   лога, резервное копирование сохранения. Читайте это первым, всегда.

Затем выбирайте нужный плагин:

| Инструкция | Добавляет |
|---|---|
| [01-resources](01-resources_RU.md) | Новый ресурс для торговли (руда, материал, товар) |
| [02-deposits](02-deposits_RU.md) | Новый тип месторождения, которое можно рисовать на карте |
| [03-depletion](03-depletion_RU.md) | Шахты, которые со временем реально исчерпывают руду |
| [04-accumulator](04-accumulator_RU.md) | Здание-аккумулятор, запасающее лишнее электричество |
| [05-needs](05-needs_RU.md) | Новый товар, за которым жители ходят в магазин |
| [06-walking](06-walking_RU.md) | Большую (или меньшую) дистанцию ходьбы/езды для жителей |
| [07-buildings](07-buildings_RU.md) | Совершенно новое здание, склонированное из существующего |

Каждая инструкция самодостаточна, но некоторые опираются друг на друга: новый
товар для магазина (`needs`) обычно начинается с нового ресурса
(`resources`), а товар, продаваемый в собственном отдельном магазине, требует
ещё и нового здания (`buildings`). Каждая инструкция ссылается на те, от
которых зависит.

## Две вещи, которые стоит запомнить перед началом

- **Закрывайте игру перед редактированием любого `.ini`-файла** и
  сохраняйте его в кодировке UTF-8 **без BOM** — почему это важно и как
  сделать это в обычном Блокноте, см. в
  [00-getting-started](00-getting-started_RU.md#4-изменение-настройки).
- **Делайте резервную копию сохранения перед экспериментами с `resources`,
  `needs` или `depletion`** — эти три плагина меняют то, что хранится
  прямо внутри файла сохранения, и не всегда обратимым образом на городе,
  который вам дорог. `deposits`, `accumulator`, `walking` и `buildings`
  безопасно включать и выключать свободно.
